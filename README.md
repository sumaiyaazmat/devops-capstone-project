## Overview
This repository contains the RESTful customer account microservice developed as part of the IBM DevOps and Software Engineering Capstone Project. It provides REST APIs to create, read, update, delete, and list customer account information.

## Project Structure
* `service/` - Microservice package (Flask REST API, models, and routes)
* `tests/` - Unit tests and test factories
* `.github/workflows/` - CI/CD pipeline definitions
